# MediQueue

## 📌 Overview

MediQueue is a modern and scalable tutor booking platform designed to connect students with skilled educators. The platform simplifies the entire learning session management process by allowing users to discover tutors, schedule sessions, manage bookings, and track their learning journey through an intuitive and user-friendly interface.

Built with performance, security, and usability in mind, MediQueue provides a seamless experience for both students and tutors.

---

## 🚀 Technology Stack

MediQueue is developed using a modern technology stack to ensure scalability, maintainability, and high performance.

- **Frontend Framework:** Next.js (App Router)
- **UI Library:** HeroUI
- **Styling:** Tailwind CSS
- **Database:** MongoDB with Mongoose
- **Data Fetching & State Management:** TanStack Query
- **Authentication:** Better Auth
- **Icons:** Lucide React

---

## ✨ Key Features

### 🔍 Smart Tutor Discovery
- Search and filter tutors based on expertise, subjects, and availability.
- Helps students quickly find the most suitable tutor for their learning needs.

### 📅 Easy Booking & Scheduling
- Simple and efficient booking system for managing tutoring sessions.
- Allows students and tutors to organize their schedules easily.

### 📊 Personalized Dashboard
- Dedicated dashboard for managing:
  - Upcoming bookings
  - Previous sessions
  - Favorite tutors
  - Account activities

### 🔐 Secure Authentication
- Reliable user authentication system powered by Better Auth.
- Ensures secure access and user data protection.

### 📱 Fully Responsive Design
- Optimized for all devices, including desktops, tablets, and mobile phones.
- Provides a smooth and consistent user experience everywhere.
